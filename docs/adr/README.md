# ADRs — Architecture Decision Records

Formato: copiar `0000-template.md`. Status: `proposto` -> `aceito` ->
`supersedido por ADR-XXXX`. **Decisão aceita nunca é editada** — cria-se um novo ADR
que a supersede.

Um ADR só existe se houver alternativa descartada. Sem alternativa, é anotação, não ADR.
